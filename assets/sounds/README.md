# Notification Sounds

Place your custom notification sound files here.

## Supported Formats:
- **iOS**: `.wav`, `.aiff`, `.caf`
- **Android**: `.wav`, `.mp3`

## Recommended:
- Use `.wav` format for best compatibility
- Keep files under 30 seconds
- Use short, clear sounds (1-3 seconds is ideal)

## Free Sound Resources:
- https://notificationsounds.com/
- https://mixkit.co/free-sound-effects/notification/
- https://www.zapsplat.com/sound-effect-categories/notification-sounds/

## Example Sound Names:
- `notification.wav` - Standard notification
- `alert.wav` - Alert/urgent sound
- `success.wav` - Success confirmation
- `message.wav` - Message received

After adding sound files, update `app.json` to include them in the `sounds` array.
